# Výklad

## Podmínka
*if*

- if (vek >= 18) spustí blok ve složených závorkách, jen když je podmínka true.
- else je větev pro opačný případ.
- else if přidá další podmínku mezi ně.

> Tip: Za if není středník. Středník by podmínku oddělil od bloku.

## Porovnání
*==*

- Čísla porovnávejte >, <, >=, <=, == a !=.
- Text se porovnává ==. "Anna" == "anna" je false.
- Do podmínky patří bool, ne přiřazení.

> Tip: Změňte vek a sledujte, která věta se vypíše.

# Kód

```
int vek = 17;
if (vek >= 18)
{
    Console.WriteLine("plnoletý");
}
else if (vek >= 15)
{
    Console.WriteLine("téměř");
}
else
{
    Console.WriteLine("ještě ne");
}
```
