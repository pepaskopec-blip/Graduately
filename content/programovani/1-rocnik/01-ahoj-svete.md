# Výklad

## Výpis
*WriteLine*

- Console.WriteLine vypíše text a odřádkuje.
- Console.Write vypíše text a zůstane na stejném řádku.
- Text se píše do uvozovek. Středník ukončuje příkaz.

> Tip: Bez středníku se program nepřeloží.

## Krátký a dlouhý zápis
*Main*

- Starší učebnice mají třídu Program a metodu Main.
- Nový projekt stejný program zapíše několika řádky bez třídy.
- Obojí spustí stejný výpis. V lekcích používáme krátký zápis.

> Tip: Krátký zápis je pořád C#. Není to jiný jazyk.

## Vyzkoušejte
*Editor*

- Vpravo je kód. Upravte ho a stiskněte Spustit.
- Výstup se objeví hned vedle.
- Obnovit ukázku vrátí původní program.

> Tip: Změňte text v uvozovkách a spusťte znovu.

# Kód

```
Console.WriteLine("Ahoj světe");
Console.Write("Toto je ");
Console.WriteLine("C#");
```
