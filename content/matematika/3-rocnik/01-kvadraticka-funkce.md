# Výklad

## f(x) = ax² + bx + c
*Parabola*

- Grafem kvadratické funkce je parabola.
- Průsečík s osou y je bod [0; c].
- U f(x) = x² − 4x + 3 je f(0) = 3.
- Osa paraboly je svislá.

> Tip: pro a > 0 má parabola minimum, pro a < 0 maximum.

## x = −b/(2a)
*Vrchol*

- x-ová souřadnice vrcholu je −b/(2a).
- U x² − 4x + 3 je to −(−4)/2 = 2.
- f(2) = 4 − 8 + 3 = −1.
- Vrchol je tedy [2; −1].

> Tip: souřadnice vrcholu pište x;y.

## Průsečíky s osou x
*Kořeny*

- x² − 4x + 3 = (x − 1)(x − 3).
- Kořeny jsou 1 a 3.
- Leží symetricky kolem osy paraboly.
- f(4) = 16 − 16 + 3 = 3, stejně jako f(0).

> Tip: kořeny jsou řešení f(x) = 0.


# Příklady

## Najděte vrchol funkce f(x) = x² − 4x + 3. Napište x a y oddělené středníkem.
= pair:2;-1
> x = 4/2 = 2 a f(2) = −1. Napište 2;-1.

## Najděte kořeny funkce f(x) = x² − 4x + 3. Oddělte je středníkem.
= set:1;3
> (x − 1)(x − 3) = 0. Napište 1;3.

## Kolik je f(0) u funkce f(x) = x² − 4x + 3?
= num:3
> f(0) = 3, to je absolutní člen. Výsledek je 3.

## Kolik je f(4) u funkce f(x) = x² − 4x + 3?
= num:3
> 16 − 16 + 3 = 3. Výsledek je 3.
